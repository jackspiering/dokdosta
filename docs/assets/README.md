# Brand assets

The whale in a nurse cap (#7, redrawn in #10). The SVGs are the sources; the PNG, ICO and JPEG files are made from them.

| File | Size | What it is for |
|---|---|---|
| `logo.svg`, `logo.png` | 2000×599 | the wordmark ("whale" navy, "nurse" cyan-blue) on a transparent background; the README header uses the PNG |
| `icon.svg`, `icon-512.png` | 512×512 | the whale without the wordmark, as a square icon |
| `apple-touch-icon.png` | 180×180 | the iOS home-screen icon size |
| `favicon.ico` | 16×16, 32×32 | the browser tab icon sizes |
| `mascot.svg`, `mascot.png` | 1024×1024 | the same whale, larger, for illustrations |
| `social-preview.jpg` | 1280×640 | GitHub's social preview image (Settings, General, Social preview: uploaded by hand, GitHub does not read it from the repository) |

The dashboard does not use these files: its assets are embedded from `internal/web`.
